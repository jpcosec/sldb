# Model browser

## Answer

The model browser is the surface that lets users inspect typed models, field contracts, and their relation to canonical structure.

## Supporting points

- It is part of the future visual UX direction.
- It makes model semantics first-class and inspectable.
- It should consume the same canonical substrate as the CLI.
