# `help` command group

## Answer

The `help` command group is the curated onboarding and command-discovery surface for the SLDB CLI.

## Supporting points

- It orients users to the intended command family.
- It reduces discovery friction without changing the underlying product contract.
- It is part of the public CLI experience even if not part of canonical structure.
