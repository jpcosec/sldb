# Semantic search

## Answer

Use semantic search when the query is concept-like and should match explicit semantic tags, section meaning, or semantic projections rather than path-like tokens.

## Supporting points

- It is driven by explicit semantic structure, not free inference.
- It is suited to conceptual retrieval needs.
- It should remain distinct from physical lookup in the refactor.
