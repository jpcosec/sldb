# Una regla puede preguntar por los tags semánticos del modelo de un documento

## Answer

El lenguaje de reglas tiene el predicado model_tag("T"), que es verdadero si el modelo del documento o alguno de sus ancestros en el DAG semántico lleva el tag T.
