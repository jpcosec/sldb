# `ast` command group

## Answer

The `ast` command group is the CLI inspection surface for normalized structural views over models, documents, sections, and fields.

## Supporting points

- It is the main debugging and introspection surface.
- It makes canonical or normalized structure inspectable to users.
- It is part of the plural-first primary interface.
