# Una lista de fricciones conocidas se poda cuando la fricción se arregla, en el mismo cambio

## Answer

Las secciones de un manual que catalogan problemas conocidos (fricciones, límites) envejecen peor que el resto: el arreglo llega al código y la entrada queda, mandando a los lectores a esquivar algo resuelto. Se poda en el mismo cambio que arregla la fricción y se deja la corrección en la tabla de verificación del manual (§16 en docs/user-manual.md).
