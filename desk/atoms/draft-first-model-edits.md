# Draft-first model edits

## Answer

Template and field edits are draft-first, and the active model contract does not change until validation and promotion succeed.

## Supporting points

- This is a stable safety contract around model evolution.
- Users can edit model structure without immediately mutating the active contract.
- Promotion is the visible commit point for contract change.
