AMBIGUEDADES
1. Contradicción sobre referencias inexistentes: «una referencia a un documento inexistente dentro de un store disponible es false» frente a «Una referencia a un documento inexistente se omite del conjunto alcanzado por un camino (all sobre conjunto vacío = true, any = false, count = 0)». Obliga a decidir si un camino a documento inexistente da `false` o se omite, cambiando el resultado de `all`/`count`.
2. Alcance de `eval` sin sujeto: «todos los documentos del store, o los de model <= X si el predicado lo restringe». No define si cualquier `model <= X`, incluso anidado bajo `not`/`any` o dentro de un camino, restringe el dominio, o solo una restricción de nivel superior. Obliga a inventar la cardinalidad de findings.
3. Sintaxis de clausura: «clausura transitiva (+): dirección saliente desde el sujeto siguiendo la relación nombrada» y la aceptación exige «clausura con ciclo», pero no fija dónde se escribe `+` ni cómo se combina con `campo`, `rel:tipo` o `^`. Obliga a inventar un contrato que GO03/GO05 consumen.
